Tooltips

One tooltip surface for the whole app, in three sizes: a label for controls whose name is hidden, a chart tooltip for values, and a card for map hovers. Each section shows today's tooltip next to the proposed one, in place. Hover or tab to the proposed icon buttons to try the timing.

The system

Built from the current chart tooltip: the name on top, muted detail lines such as "Accounts: 1,184", and a large figure where the tooltip answers "how much". The only changes to it: figures use the text colour, a small swatch carries the slice colour, and the same shape now covers labels, revenue and the map. Same surface everywhere: the tooltip token, one hairline border, 8px corners and the shared float shadow. Text uses text tokens only. Colour appears only as a small swatch that ties a chart tooltip to its slice or tile. No arrows: two of the three variants follow the pointer, so arrows would only appear on some tooltips, and a hairline arrow joined to a shadowed box never looks clean at this size.

Settled defaults

  • Labels only where a name is hidden. Search shows its name and its key, so it gets no tooltip.
  • The map card stays a tooltip variant. Same surface and lines, with the centre count as its large figure.
  • One surface for every variant. Labels keep the chart tooltip's surface rather than a tinted or inverted one.
