Also worth doing: row density

Rows are 72 to 80px tall today because the NASSCOM badge sits on its own line under the name. Moving it inline after the name (or into its own narrow column) brings rows down to 48px. Combined with V1, that's about 10 visible rows instead of about 5.5. Use the Compact rows toggle above to see it in every variant.

Grid layout: what changes

Switch the page to Grid at the top. V0 shows today's grid. The other variants show the same tiles in the new shell, and Compact tiles swaps in the proposed tile.

  • Four levels deep today: card, then the bordered box, then a sort bar holding one unlabelled icon button, then the tiles. With sort removed from Grid, that bar goes too, and the tiles sit straight in the card.
  • Drop the "View Details" button. The whole tile already opens the account, and a button inside a clickable tile means two nested controls. An arrow appears on hover instead.
  • Add a checkbox to each tile. Grid has no selection today, so the export bar only works in Table. With a checkbox, both layouts share one selection.
  • Let the metadata use the width. Today "Industry" and "Revenue" are label/value pairs capped at 160px, so "Business Software Solutions" gets cut off. Labels above values in three columns (Industry, Revenue, Headcount) fit more and stay readable.
  • The proposed tile is about 125px tall instead of about 220px, so roughly twice as many accounts fit on one screen (about 11 instead of 5).

Reference patterns

LinearThe list is the surface. No card around it, display options in the view header, and grouping and layout behind one small control.
Stripe DashboardThe table is the card. Column headers sit on the card's top edge, with the "Viewing 1 to 20 of N" and prev/next pager in a footer strip.
